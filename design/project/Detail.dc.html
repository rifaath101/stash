A practical guide to database indexes

Open original

Summary

Explains how indexes let the database find rows without scanning the whole table, why Postgres sometimes ignores an index, and how to read a query plan to find the slow part of a query.

Key points

  • An index is a sorted lookup structure, like the index at the back of a book.
  • Indexes speed up reads but slow down writes a little.
  • Use EXPLAIN ANALYZE to see whether a query uses an index.
